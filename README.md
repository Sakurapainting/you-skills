# You Skills

[中文说明](README.zh-CN.md)

A collection of reusable Copilot skills and workflow assets.

## Overview

This repository hosts skill packages and supporting documentation designed to improve developer workflows in VS Code with GitHub Copilot.

## Features

- Reusable skill packages for specific engineering tasks.
- Clear `SKILL.md` instructions per skill.
- Easy extension with additional skill folders.

## Project Structure

- `pr-analyze/`: Skill package for pull request analysis workflows.

## Getting Started

1. Clone the repository.
2. Open the folder in VS Code.
3. Review each skill folder and read its `SKILL.md`.
4. Adjust or extend skill content based on your team needs.

## Contributing

Contributions are welcome.

1. Fork the repository.
2. Create a feature branch: `git checkout -b feat/your-change`.
3. Keep changes focused and document intent clearly.
4. Commit with meaningful messages.
5. Open a pull request with:
	- A concise summary of what changed
	- Why the change is needed
	- Any validation notes
